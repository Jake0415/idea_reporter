# P9 S3 수정 지시 — 4회차(마지막 수정) (Claude 통과·낮음 1, OpenAI 높음 0·중간 2·낮음 1)

규칙 동일(커밋·docs 수정·키 출력 금지, 실제 LLM 호출 금지).
(OpenAI 낮음 "플랜 문서 수정"은 Claude가 사용자 요청으로 직접 고친 것이라 해당 없음.)

1. **[중간] 판정 설정 변경 시 낡은 결과 재사용** — 재사용 키에 판정 설정(`threshold`, 가중치 6개, 관문 수치: 수요 근거 수·출처 수·데이터 일수, 허용 라이선스 목록)의 해시를 넣는다. 더 나아가 저장된 원문 응답이 있으면 **재사용 시 판정만 현재 설정으로 다시 계산**하는 방식도 허용(LLM 0회) — 이 경우 재사용 키에서 판정 설정은 빼도 된다. 둘 중 하나로 구현하고 보고. 테스트(threshold 3.5→4.5).
2. **[중간] 읽을 수 없는 일일 결과 파일** — `hasDailyRun`에서 역직렬화에 실패한 파일은 "분류 있는 실행"으로 세지 않고, 콘솔에 "읽을 수 없는 실행 파일: 경로" 경고(Claude 낮음). 과거 채우기는 `out/backfill/`에만 쓰므로 그 날을 채워도 일일 파일을 덮어쓰지 않음(확인). 테스트(깨진 state + 생략 실행 → 과거 채우기가 채움 → 트렌드가 backfill 사용).

## 완료 기준
- `:core:test --rerun-tasks` 통과. 1~2 한 줄씩 + 테스트 개수.
