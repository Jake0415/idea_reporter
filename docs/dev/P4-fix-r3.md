# P4 수정 지시 — 3회차 (Claude·OpenAI 합의)

판정: Claude "통과"(낮음 1), OpenAI "수정 필요"(중간 2). 1·3·4 양쪽 통과. 규칙 동일(커밋·docs·프롬프트 수정·키 출력 금지, 실제 LLM 실행 금지).

## A. 공통(양쪽 지적)
1. **수요 대표 승격은 부족분만** (Selector.kt:27): 대표는 기존 순위(정렬 1순위)로 고른다. 그다음 `minDemandCandidates > 0`이고 최종 수요 후보가 목표보다 적을 때만, 부족한 수만큼 "수요 신호가 병합된 기술 대표" 주제를 수요 점수 높은 순으로 골라 대표를 수요 신호로 교체한다(교체된 기술 항목은 `mergedUrls`/병합 신호로 유지, 주제 정렬 위치는 원래 대표 순위 유지). `0`이면 승격 없음. 테스트: 0일 때 승격 없음, 다른 주제로 이미 목표 충족 시 승격 없음, 부족할 때만 승격.

## B. OpenAI
2. **[중간] 카드 간 중복** (IdeaGenerator.kt:138): 검증 후 카드끼리 비교해, 근거 itemId 집합(tech+demand+competitors, 병합 URL은 원래 항목으로 정규화)이 같거나 한쪽이 다른 쪽에 완전히 포함되면서 같은 주제(topicKey)인 카드는 앞 카드만 남긴다(뒤 카드는 실행 기록 경고). 테스트: 같은 근거로 두 장을 반환하는 생성기 응답.
