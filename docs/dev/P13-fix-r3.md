# P13 수정 지시 — 3회차 (OpenAI 높음 3·중간 5, Claude 높음 1·중간 2)

규칙은 같다. 커밋·docs 수정·실제 호출 금지.

**결정 (Claude):** "오늘 실행을 막지 않는다"는 **지난 날짜·격리 대상**에만 적용한다. **같은 날짜·같은 단계의 Batch가 대기 중이거나, 복구 상한 때문에 확인하지 못했을 때는 동기로 다시 부르지 않는다.** 1회차 2번처럼 select 이후를 건너뛰고 daily 메일을 보류한다. 원칙은 "불확실하면 다시 내지 않는다"이다.

## 높음
1. **Batch 생성 오류 분류.** (둘 다 지적)
   - **확정 거절**은 HTTP 400·401·403·404·413·422 같은 4xx 검증·인증 오류다(429 제외). 이것만 동기로 대체한다.
   - **불확실**은 다음 경우다. 의도 기록을 유지하고 1회차 3번 경로를 탄다.
     - 429, 5xx, 529
     - 연결 끊김·시간 초과
     - 응답 파싱 실패
   - 테스트: 생성 요청에 503 → 동기 호출 0건, 의도 기록 유지, 다음 실행에서 `list`로 채택.
2. **같은 날짜 미결 Batch는 동기로 다시 부르지 않는다.** (둘 다 지적)
   - 라우터가 기존 체크포인트를 `pending=false`로 바꾸는 분기를 없앤다.
   - 오늘 날짜·같은 단계 체크포인트가 다음 상태면 그 단계는 대기로 처리한다(분류→select 이후 중단, 작성→작성 생략).
     - pending
     - 복구 상한 초과로 미확인
     - 정산만 실패
   - 이미 내려받은 결과 파일이 있으면 항목·지문 매칭으로 재사용한다.
3. **격리 중 정산 실패.** (OpenAI)
   - 정산이 하나라도 실패하면 격리하지 않는다. 체크포인트에 `settleRetry`를 표시하고 다음 실행에서 정산만 다시 시도한다.
   - 정산 재시도가 7일 이상 실패하면 격리하되, 미정산 예약 ID 목록을 `quarantine/<id>.unsettled.json`에 남긴다.
   - 시작 시 복구는 quarantine의 `unsettled`도 정산을 시도한다.
   - `Files.move` 실패도 같은 방식으로 다음 실행에서 다시 시도하되, 예외로 실행을 끝내지 않는다.

## 중간
4. **복구 상한과 대기 한도를 분리한다.** 복구 10분 상한은 "오늘 확인을 멈추는 기준"일 뿐, **취소 조건으로 쓰지 않는다.** 취소는 그 Batch 자체의 `maxWaitMinutes`·마감 기준으로만 한다. 원장 읽기 실패는 만료 검사를 막지 않는다. 만료 판정을 먼저 하고, 원장 오류는 issue로 남긴다.
5. **Backfill 체크포인트.** 일일 실행이 Backfill 체크포인트를 회수할 때도 완료 포인터를 남긴다. Backfill이 날짜로 결과 파일을 찾을 수 있는 색인(`out/batch/index.json`: 단계·날짜 → batchId·결과 파일)을 둔다.
6. **같은 날짜 메일 보류.** 실행 **후** 해당 날짜에 미결 분류 체크포인트가 남아 있으면 daily 메일(신규·재시도)을 보류한다. 실행 전 상태가 아니라 실행 후 상태로 판정한다.
7. **마감 초과 issue.** 트렌드 게시, 메일 재시도, 신규 발송 뒤에도 마감 초과를 확인해 issue를 남긴다.
8. **소비 완료 시점.** `.done`은 호출자가 결과를 적용하고 보고서(또는 Backfill 날짜 결과)를 저장한 **뒤에** 기록한다. 카드 작성과 Backfill에도 같은 보존 경로를 둔다.
9. **인증 실패(401) 처리.** (Claude) 즉시 격리하지 않는다. 키 없음과 같이 48시간 대기한 뒤 격리한다. 키를 바꾸면 결과를 받을 수 있게 하기 위해서다.

## 낮음
10. 보충 검색 단계의 작성 여유분은 보충 자료 한도(3개·120·300자)를 더한 입력 기준으로 계산한다. (Claude)

## 테스트 (추가)
- 생성 503·429·연결 끊김 → 동기 0건
- 같은 날짜 pending·복구 상한 초과 → 동기 0건, select 이후 중단, daily 메일 보류
- 격리 중 정산 실패 → 격리 안 함, 다음 실행에서 정산
- 복구 상한이 취소를 일으키지 않음
- 원장 읽기 실패에도 48시간 만료
- Backfill 색인 재사용
- 실행 후 미결 판정 메일 보류
- 메일 뒤 마감 초과 issue
- 보고서 저장 전 중단 → 7일 정리 대상 아님
- 401 → 48시간 대기
