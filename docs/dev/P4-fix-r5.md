# P4 수정 지시 — 5회차 (최종 리뷰 전 마무리)

판정: Claude "통과", OpenAI "수정 필요"(중간 1: 포함 관계만으로 서로 다른 아이디어 카드가 제거됨). 다음 리뷰가 5회차(한도). 규칙 동일(커밋·docs·프롬프트 수정·키 출력 금지, 실제 LLM 실행 금지).

1. **중복 판정을 "같은 문제"로 좁힘** (IdeaGenerator.kt:146): 뒤 카드를 자동 제외하는 경우는 둘 중 하나뿐.
   - (a) 정규화한 전체 근거 집합이 **같다**.
   - (b) 수요 근거 집합(demandSignals, 정규화 후)이 **같고 비어 있지 않으며**, 기술 근거 topicKey 집합이 겹친다(= 같은 수요 문제를 같은 기술로 푼 변형).
   - 그 외(포함 관계만 있음, 수요 근거가 다름)는 둘 다 남긴다.
   - 테스트: OpenAI 사례(앞 카드 T+D1+D2, 뒤 카드 T+D2 → 둘 다 유지), 기존 [A,B]/[B,A] 테스트는 (b)에 맞게 수요 근거를 같게 조정해 제외 유지, 기존 동일 근거 테스트 유지.
