# P7 S1 수정 지시 — 5회차(마지막) (Claude 통과·낮음 1, OpenAI 높음 0·중간 1·낮음 3)

규칙 동일(커밋·docs·프롬프트 수정·키 출력 금지, LLM·네트워크 금지). 이번이 마지막 회차다.

1. **[중간] state가 없을 때 대표 관측** (TrendInput) — 날짜별 대표 관측은 state가 있으면 지금 규칙, **state가 없으면 같은 날 본 파일(`out/<날짜>.json`)**을 쓴다. 본 파일도 없을 때만 그날 가장 늦은 `runs/` 보관본. 보관본은 원본 분류 색인에는 계속 포함. 테스트: 본 파일 + 더 늦은 보관본 + state 없음 → 본 파일의 분류·탈락·카드로 집계.
2. **[낮음] 테스트 보강만** — (a) 그날 본 파일·state 없이 `runs/` 보관본만 있는 기간 밖 날짜에서 원본 분류 발견, 기준일 이후 보관본은 색인에서 제외, (b) 요약 신규 우선·데이터 부족 시 건수 우선 직접 검증, (c) 기본 설정 스팸 묶음 19개 → 과열 아님, 20개 → 과열.
3. (Claude 낮음, 이번엔 코드 변경 없음) 원본 색인 전체 파일 읽기 성능은 데이터가 쌓인 뒤 판단 — 손대지 않는다.

## 완료 기준
- `:core:test --rerun-tasks` 통과. 1~2 한 줄씩 + 테스트 개수.
