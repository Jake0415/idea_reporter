# P8 S2 수정 지시 — 3회차 (Claude 통과, OpenAI 높음 0·중간 2·낮음 1)

규칙 동일(커밋·docs·프롬프트 수정·키 출력 금지, 실제 수집·LLM 실행 금지).

1. **[중간] 강제 갱신 완료 직후 중단 시 재분류** (Backfill.kt) — 결과 파일 확정과 캐시 `replacing=false` 갱신의 순서를 바꾸거나, 결과 파일에 **수집 캐시 해시**를 기록해 재실행 때 `replacing=true`라도 결과 파일의 해시가 현재 캐시와 같으면 그 날을 완료로 보고 `replacing`만 정리한다(분류 호출 0회). 테스트: 결과 저장 후 캐시 갱신 직전 실패 주입 → 재실행 시 분류 0회.
2. **[중간] 테스트 보강** — r2 3번 테스트 픽스처: 첫 관측은 RSS만, **두 번째 관측에만** `alsoSeenIn=hn` → 비교 건수에 포함되어야 함(순서 회귀 검출).
3. **[낮음] 테스트 보강** — 백필 날짜가 섞인 구간에서 중복 제거로 사라진 관측의 출처가 ◆를 켜지 않음.
