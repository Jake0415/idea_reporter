# P3 수정 지시 — 2회차 (Claude·OpenAI 합의)

판정: Claude "통과"(낮음 3), OpenAI "수정 필요"(높음 1·중간 2). 1~9는 양쪽 모두 반영 확인. 규칙 동일(커밋·docs·프롬프트 수정·키 출력·HTML 스크레이핑 금지).

## A. 공통(양쪽 지적)
1. **RSS 피드 이름 중복** (SourceCap.kt:25, RssAdapter.kt:54·92): 설정 검증에서 같은 `name`의 피드를 거부(오류 메시지에 URL 넣지 말고 이름만). 테스트.

## B. OpenAI
2. **[높음] 항목 링크로 피드 토큰 노출** (RssAdapter.kt:88): 최종 `Item.url`(및 discussionUrl 등 결과에 남는 링크)에서도, 피드 요청 URL에 있던 쿼리 파라미터 값과 사용자 정보(userinfo)가 들어 있으면 제거한다. 피드 URL을 그대로 항목 링크로 반환하는 피드로 회귀 테스트(결과 JSON 어디에도 가짜 토큰 없음).
3. **[중간] RSS 시간 초과 시 성공 피드 유실** (Pipeline.kt:125): 출처 전체 제한(45초) 안에서 피드별 기한을 두고, 시간 초과는 해당 피드 실패로 기록하며 이미 수집한 항목은 반환. 느린 피드(MockWebServer 지연) 테스트.

## C. Claude(낮음, 함께 처리)
4. Reddit 댓글을 분류용·작성용에서 두 번 요청하지 않도록 실행 안 캐시(Enricher.kt:44·51-53, HN 캐시와 같은 방식).
5. RSS 일부 피드 실패는 출처 실패가 아니라 "부분 실패"로 표시(`failedSources`에 넣지 말고 경고로 남김; 전부 실패일 때만 실패 출처).
