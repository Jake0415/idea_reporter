# P7 S1 수정 지시 — 3회차 (Claude 통과·낮음 4, OpenAI 수정 필요·높음 1·중간 2·낮음 2)

규칙 동일(커밋·docs·프롬프트 수정·키 출력 금지, LLM·네트워크 금지). 결정이 엇갈린 항목은 아래 결정을 따른다.

## 높음
1. **같은 날 재실행의 재등장 원본 분류 누락** (TrendInput, OpenAI) — 재등장 원본 분류 조회용 색인은 날짜별 대표 실행뿐 아니라 **기간 안 모든 실행**(본 파일, state, `out/runs/` 보관본)의 `classified`를 모아 itemKey → 가장 이른 분류로 만든다. 집계용 날짜별 관측은 지금처럼 대표 실행 기준. 테스트: 오전 실행(runs/ 보관본)에서 분류된 항목이 오후 재실행에서 ALREADY_SEEN → 원래 태그로 집계.

## 중간
2. **◆와 뜨는 테마 기준 충돌 — 결정:** ◆ 조건에 **이번 주 ≥ 2건**(뜨는 테마 최소 기준과 같은 설정값)을 추가한다. 그러면 ◆ 후보는 항상 뜨는 테마 자격을 가진다. 뜨는 테마 표 = ◆ 후보 먼저 + 나머지, 전체 **최대 10행**(◆가 10개를 넘으면 ◆ 상위 10개, 제목 ◆ 수는 표에 보인 ◆ 수와 같게 하고 넘친 수는 "외 n" 표시). 기존 1건 후보 테스트를 새 규칙으로 고친다.
3. **묶음 교체 중단 시 섞임 — 결정:** 완전한 다중 파일 원자성 대신 **공개 순서로 정합성 보장**: html → txt → themes.json → 마지막에 `<기준일>.json`(공식 결과, 커밋 표시). 읽는 쪽은 json을 기준으로 삼으므로 중간 중단 시 json은 이전 것 그대로다. 교체 중 실패하면 이미 교체한 파일을 백업으로 되돌리는 기존 복원은 유지. 순서를 테스트로 고정(교체 순서 기록용 훅 또는 3번째 교체에서 예외 주입 → json 미변경 확인).

## 낮음
4. **복수형 제거가 단어를 망가뜨림** (Claude, 실제 `script-analysi`) — 끝 `s` 제거 예외: `ss`·`us`·`is`·`sis`·`ics`·`ews`·`ios`·`ops`·`as`로 끝나는 말, 그리고 예외 목록(`news`, `ios`, `devops`, `mlops`, `kubernetes`, `aws`, `gas`, `canvas`, `analytics`, `physics`, `windows`, `postgres`, `redis`, `nodejs`, `js`). 하이픈 태그는 **마지막 조각에만** 적용. 테스트.
5. **카드는 본 파일 우선** (Claude) — state 보완 시 `cards`는 같은 날 본 파일(`out/<날짜>.json`, 그날 발행된 카드)을 우선, 없을 때만 최신 실행. 테스트.
6. **지는 테마 기준 일평균** (Claude) — "앞 3주 평균 ≥ 2"도 증가율과 같은 일평균 정규화 기준으로(일평균 × 7 ≥ 2). 테스트.
7. **과열 묶음 과대 연결** (Claude, 실제 `ai--manus` 77개) — 설명 기준 연결은 **정규화 설명 20자 이상**일 때만. 이름은 소유자 제외 저장소 이름 소문자·`-`/`_` 정리 후 비교. 테스트.
8. **TXT 표 `|` 깨짐** (OpenAI) — TXT 셀 안의 `|`는 `/`로 바꾸고 줄바꿈은 공백으로. 테스트.
9. **과열 union 전이 테스트** (OpenAI) — A–B 이름만 같음, B–C 설명만 같음(20자 이상) → 한 묶음. 테스트만 추가.
