# X1 수정 3회차 (OpenAI 코드 리뷰 + Claude 코드 리뷰 + Claude UX 리뷰 합의)

규칙은 X1-expand.md와 같다. 커밋하지 않는다. 끝나면 완료 기준의 Gradle 작업을 모두 통과시킨다.

## 코드

**1. [중간] 병합 근거가 씨앗에 일부만 들어간다** (ExpansionSeeds:79-81)
- **문제:** 씨앗에 기술 항목과 같이 쓸 수요 항목만 들어가고, 그 항목에 병합된 구성원은 빠진다. 모델이 병합된 제품을 인용하면 확장 카드가 CITATION으로 탈락한다.
- **수정:**
  - 씨앗에 인용 가능한 (itemId, url) 쌍 목록을 그대로 넣는다. 기술 항목과 짝 항목, 그리고 각각의 검증된 병합 구성원을 모두 포함한다.
  - 씨앗 소속 검사는 이 목록으로 한다.
  - 프롬프트는 이 쌍을 그대로 복사하라고 지시한다.
  - 테스트를 추가한다.

**2. [중간] 원본 없는 체크포인트의 ID 복구가 새 버전 Batch까지 적용된다** (MessageBatch:644, IdeaGenerator:330)
- **문제:** 새 버전 Batch를 복구하면 그사이 다시 계산된 씨앗 때문에 결제한 확장 카드의 `seedId`가 탈락할 수 있다.
- **수정:**
  - ID만으로 복구하는 예외는 구버전(스키마 버전 없음)에만 적용한다.
  - 새 버전은 제출할 때 쓴 씨앗 정보(id, 렌즈, 고객, 인용 가능 쌍)를 체크포인트에 보존한다. 비밀값이 없는 데이터이니 공개 체크포인트에도 남긴다.
  - 복구할 때는 보존한 씨앗으로 검증한다.
  - 테스트를 추가한다.

**3. [중간] Batch를 기다리는 동안 만든 요청 카드가 반복 검사에서 빠진다** (FullPipeline:252)
- **수정:**
  - 제출 당시 이력은 프롬프트를 재현하는 데만 쓴다.
  - 게시 전 반복 검사에는 최신 요청 카드 이력을 합친다.
  - 테스트를 추가한다.

**4. [중간] 데이터 브랜치에서 가져오면 로컬 씨앗 기록이 덮어써진다** (DataSync:185)
- **수정:**
  - `expansion-seeds.json`은 덮어쓰지 않는다. 양쪽의 유효한 행을 합치고(중복 제거), 보존 기간을 적용한다.
  - 테스트를 추가한다.

**5. [중간] 미래 날짜 한 행 때문에 정상 씨앗 기록이 지워진다** (Main:470 등)
- **수정:**
  - 정리 기준일은 실행일로 한다. 날짜 비교는 `LocalDate`로 한다.
  - 실행일보다 미래인 행은 무시한다.
  - 테스트를 추가한다.

**6. [낮음] 피드백 가중치 때문에 일부 렌즈가 영영 안 나온다** (ExpansionSeeds:59)
- **수정:** 켜진 렌즈가 `켜진 렌즈 수 × 2`일 동안 한 번도 제안되지 않았다면, 다음 씨앗에 순번을 보장한다.
- `seedCount=1`, `seedHistoryDays=7` 사례로 테스트를 추가한다.

## UX

**1. [중간] 상세 화면 순서**
- `Evidence(R.string.evidence, …)`(근거 링크 전체)와 보충 자료 블록을 `caveats`(확인 필요) 뒤로 옮긴다.
- 최종 순서는 이렇다: 쓸 수 있는 기술 → 사람들의 요청·불편 → 이미 나온 제품 → [AI 제안(추정) 상자] → 과거 기록 → 실행 판단 → 확인 필요 → 근거 링크 → 보충 자료
- 상세 캡처를 다시 찍는다.

**2. [낮음] 다크 모드의 비활성 스위치**
- 다크 모드에서 켜진 비활성 스위치가 구분되도록, RunOption의 Switch에 아래 색을 준다.
  - `disabledCheckedTrackColor = primary.copy(alpha = 0.38f)`
  - `disabledCheckedThumbColor = surface`
- `dark/criteria-expansion-off.png`를 다시 찍는다.
