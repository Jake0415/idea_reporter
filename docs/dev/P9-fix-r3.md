# P9 S3 수정 지시 — 3회차 (Claude 통과·낮음 1, OpenAI 높음 1·중간 2·낮음 1)

규칙 동일(커밋·docs 수정·키 출력 금지, 실제 LLM 호출 금지).

## 높음
1. **유료 단계 생략 날짜를 과거 채우기로 복구 불가** — 월 상한으로 분류·작성을 생략한 일일 실행은 결과 report에 `paidStagesSkipped: true`(기본 false, 직렬화 호환)를 남긴다. 과거 채우기의 "실제 실행 있음" 판정은 **분류가 있는 실행**(paidStagesSkipped=false)만 센다 — 생략 실행만 있는 날은 채울 수 있다. TrendInput은 그날 대표 관측을 고를 때 생략 실행보다 backfill 결과를 우선(둘 다 없으면 생략 실행, 분류 없음). 테스트: 상한으로 생략된 날 → 상한 해제 후 `--backfill` 이 그 날을 채움 → 트렌드가 backfill 분류를 씀.

## 중간
2. **해제된 차단이 상한을 되돌리면 재활성** — 해제 조건을 만족하는 순간(설정 값 변경 감지) 차단 기록을 **삭제**한다(또는 `released: true`로 표시해 다시 보지 않음). 이후 원래 값으로 돌려도 새 초과 정산이 없으면 차단 없음. 테스트(1.00→1.10→1.00).
3. **같은 날짜 리포트 재생성 시 낡은 분석 재사용** — 재사용 키를 **실제 분석 입력의 해시**(테마 지표·근거 itemId·URL·프로필·점수·본문 요약 포함 직렬화 JSON) + 프롬프트 버전·해시 + 구성 값으로 바꾼다. 입력이 하나라도 바뀌면 재사용 안 함. 테스트(같은 날짜, 근거 URL만 교체).

## 낮음
4. 다음 달 1일 자동 해제 테스트(설정 그대로, 가짜 공급자 다시 호출됨).
