# 리뷰 방식 (Claude + OpenAI 동시 리뷰 → 합의)

1. Codex가 브리프대로 구현(커밋 없이 작업 트리에 남김).
2. **동시에** 두 리뷰를 돌린다.
   - Claude 리뷰: 작업 트리 diff를 설계(design.md·menu.md)·브리프·안전 규칙 기준으로 검토.
   - OpenAI 리뷰: `codex exec review --uncommitted`(Codex 리뷰 모드).
3. 두 결과를 맞춰 **합의 목록**을 만든다.
   - 둘 다 지적 → 수정 대상.
   - 한쪽만 지적 → 코드·실행으로 사실 확인 후, 버그·설계 위반·보안이면 수정 대상, 취향이면 제외.
4. 합의 목록만 Codex에 수정 지시 → 테스트 → 다시 2로.
5. **반복은 단계당 최대 5회.** 5회 안에 끝나지 않으면 멈추고 남은 지적을 기록해 보고한다.
6. 통과하면 Claude가 커밋하고 GitHub에 푸시한다.

기록: `docs/dev/log.md`에 단계별 리뷰 회차·합의 지적·처리 결과를 남긴다.
