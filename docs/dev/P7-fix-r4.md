# P7 S1 수정 지시 — 4회차 (Claude 통과·낮음 2, OpenAI 수정 필요·높음 1·중간 1·낮음 1)

규칙 동일(커밋·docs·프롬프트 수정·키 출력 금지, LLM·네트워크 금지).

1. **[높음] 기간 밖 최초 분류 누락** (TrendInput) — 재등장 원본 색인은 기간과 무관하게 **기준일 이하의 모든 실행**(본 파일, state, `out/runs/` 보관본)에서 만든다(가장 이른 분류 우선, 기존 정렬 규칙 유지). 집계 기간은 그대로. 테스트: 기간 밖 날짜의 runs/ 보관본에만 원본 분류가 있고 그날 state·본 파일에는 없을 때 → 원래 태그로 집계.
2. **[중간] 요약 "가장 뜬 테마"** — ◆ 우선 정렬 표가 아니라 **증가율 순위**(신규 최상위, 데이터 부족이면 이번 주 건수 순) 1위를 쓴다. 테스트: ◆ 1.5배 테마와 ◆ 아닌 5배 테마(수요 0)가 있을 때 요약은 5배 테마, 표 첫 행은 ◆ 테마.
3. **[낮음] 과열 설명 19자 경계 테스트** — 이름이 다른 두 저장소가 같은 19자 설명만 공유 → 별도 묶음. 테스트만 추가.
4. (Claude 낮음) `trend.default.json`의 `synonyms`에 `gpus→gpu`, `apis→api`, `loras→lora`, `llamas→llama`를 추가하고 테스트 1개.

## 완료 기준
- `:core:test --rerun-tasks` 통과. 1~4 한 줄씩 + 테스트 개수.
