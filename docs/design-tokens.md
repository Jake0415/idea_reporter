## 메일 (아이디어 메일 · 트렌드 메일)

- 인라인 CSS + 표(table) 배치만. 웹폰트·이미지·스크립트·`<style>`·`rgba`·CSS 변수·그림자 없음(테스트가 검사).
- 폭 640px 가운데 정렬, 바탕 흰색. 다크 모드는 메일 앱의 자동 반전에 맡긴다.
- 머리: 큰 제목(22/700, 예: "AI 아이디어 · 11월 19일") + 한 줄 메타(카드 수·단계별 건수, `text-2` 12px). 실패는 작은 경고 상자 "실패 출처 · … · 나머지 출처로 만들었습니다".
- 아이디어 카드: 테두리 상자(radius 10, padding 16) — 제목 → 한 줄 설명 → 배지 → 오늘 고른 이유 → 근거 링크 2개(`link`) → 가장 큰 위험.
- 트렌드 표: 6~7열 표는 폰 폭에서 넘치므로 **행마다 한 덩어리**(이름 굵게 → "머리 값 · …" 한 줄 → 설명·예시 줄)로 쌓는다.
- "앱에서 보기"(`ideacollector://`)는 앱이 나오기 전까지 숨김(`HtmlRenderer(appLinks = false)`, 4단계에서 켬). 텍스트 본문도 같다.
