# 기술 신호 — 포함 기준

**새로 가능해진 기술**을 알려 주는 항목. 1인 개발자가 서비스의 재료로 쓸 수 있는가가 핵심이다.

## 포함
- 새 모델·체크포인트 공개(공개 가중치, 새 API 모델)
- 오픈소스 라이브러리·도구·에이전트 프레임워크·개발 도구
- 실제로 쓸 수 있게 된 API·기능 출시(가격·사용 조건이 나온 것)
- 비용·속도·품질을 크게 바꾼 기법이나 논문(재현 코드가 있으면 우선)
- 개발자가 가져다 쓸 수 있는 데이터셋·벤치마크·평가 도구

## 제외 (다른 프로필 또는 버림)
- 완성된 소비자용 제품·서비스 출시 → `market-signal`
- 사람들의 불편·요청 → `demand-signal`
- 투자·인사·실적·인수 소식만 있는 글 → 버림
- 정책·규제·윤리 일반 논쟁 → 버림
- AI와 관계없는 기술 소식 → 버림

## 애매할 때
- "오픈소스 도구 출시(Show HN)"는 개발자가 재료로 쓰는 것이면 여기, 최종 사용자용 앱이면 `market-signal`.
- 발표만 있고 쓸 수 없는 것(대기자 명단, 일정·가격 없음)은 여기에 넣되 낮게 평가한다.
