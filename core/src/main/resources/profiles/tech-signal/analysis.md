# 쓸 수 있는 기술 — 평가표 (0~10)

질문: **1인 개발자가 이것을 재료로 지금 새로운 서비스를 만들 수 있는가?**

| 점수 | 기준 |
|---|---|
| 9–10 | 지금 바로 쓸 수 있고(공개 가중치·API 즉시 사용), 허용적인 라이선스이며, 이전에는 비싸거나 불가능했던 일을 1인도 할 수 있게 만든다. 문서·예제가 충분하다. |
| 7–8 | 쓸 수 있고 실용적인 개선이 크다(비용·속도·품질). 다만 라이선스 제한, 초기 버전, 특정 환경 의존 같은 제약이 있다. |
| 5–6 | 흥미롭지만 성숙도가 낮다(데모·연구 코드, 문서 부족). 또는 기존 도구 대비 점진적인 개선이다. |
| 3–4 | 사용 조건이 불명확하다(발표만, 대기자 명단, 가격·일정 없음). 또는 이미 흔한 도구의 사소한 업데이트다. |
| 0–2 | 스팸·홍보·스타 조작 의심, AI와 무관, 근거 없는 주장. |

## 판단 요령
- **라이선스:** MIT·Apache-2.0·BSD는 그대로, AGPL·비상업·연구 전용은 1~2점 낮추고 이유에 라이선스를 적는다. 알 수 없으면 "라이선스 불명"이라고 적는다.
- **실제 사용 가능 여부**가 화제성보다 중요하다. 스타 수·HN 점수는 화제성일 뿐 품질의 근거가 아니다.
- **업체가 말한 성능·가격**은 독립 확인이 없으면 이유에 "업체 주장"이라고 밝힌다(점수를 깎지는 않는다).
- 대규모 학습·전용 하드웨어가 있어야만 쓸 수 있으면 1인 활용성이 낮으므로 5점 이하로 둔다.
- 이유는 한 문장, 요약은 한국어 한 문장, 태그는 구체적인 주제 3~5개(예: `local-llm`, `voice-agent`, `rag`).
