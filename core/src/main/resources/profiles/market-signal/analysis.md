# 경쟁 제품 — 평가표 (0~10)

질문: **이 제품이 수요를 증명하면서, 1인이 차별화할 빈틈을 보여 주는가?**

| 점수 | 기준 |
|---|---|
| 9–10 | 반응이 크고 분명한 수요를 증명한다. 동시에 눈에 띄는 빈틈이 있다(구체적인 불만, 비싼 가격, 특정 대상·언어·플랫폼 미지원). |
| 7–8 | 반응이 좋고 대상이 분명하다. 빈틈이 일부 보인다. |
| 5–6 | 평범한 출시다. 빈틈이 불분명하다. |
| 3–4 | 이미 포화된 분야의 비슷한 제품이고 반응이 약하다. |
| 0–2 | 홍보성 글, 실체 불명, AI와 무관. |

## 판단 요령
- 빈틈은 **댓글·후기에 실제로 적힌 불만**으로 판단한다. 추천 수는 합의의 근거가 아니다.
- 대형 회사 제품은 수요 증명으로는 강하지만 정면 경쟁은 어렵다. 이유에 "대형 회사 제품"이라고 적고, 틈새(특정 대상·지역·작업)를 찾을 수 있을 때만 7점 이상을 준다.
- 업체가 말한 사용자 수·성과는 독립 확인이 없으면 "업체 주장"이라고 밝힌다.
- 요약은 한국어 한 문장, 태그는 구체적인 주제 3~5개.
