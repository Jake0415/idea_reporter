# 사람들의 요청·불편 — 포함 기준

**사람들이 원하는 것**을 보여 주는 항목. 누가 어떤 상황에서 무엇 때문에 불편한지가 드러나야 한다.

## 포함
- 특정 작업의 불편·반복 작업에 대한 호소
- "~하는 도구 있나요?", "~를 어떻게 하세요?" 같은 요청
- 기존 도구·서비스에 대한 불만, 떠난 이유, 우회 방법 공유
- 이미 돈이나 시간을 쓰고 있다는 사례(유료 도구, 수작업, 외주)
- 작업 흐름을 공유하면서 드러난 막히는 지점

## 제외 (다른 프로필 또는 버림)
- 새 모델·도구 자체에 대한 소개 → `tech-signal`
- 제품 출시·홍보 → `market-signal`
- 뉴스 공유, 밈, 일반 잡담 → 버림
- 정치·윤리 논쟁만 있는 글 → 버림

## 애매할 때
- 제품 출시 글이라도 **댓글에 구체적인 불만·요청**이 많으면, 글은 `market-signal`로 두고 그 댓글은 2단계 보강에서 수요 근거로 쓴다.
