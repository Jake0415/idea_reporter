# 사람들의 요청·불편 — 평가표 (0~10)

질문: **AI로 풀 수 있는, 구체적이고 반복되는 불편이 있는가?**

| 점수 | 기준 |
|---|---|
| 9–10 | 구체적인 사용자·상황·불편이 있고, 여러 사람이 같은 문제를 겪는다는 내용상의 증거(같은 경험을 적은 댓글)가 있다. 이미 돈이나 시간을 쓰는 우회 방법이 있고, AI로 풀 수 있는 형태다. |
| 7–8 | 불편이 구체적이고 대상이 분명하다. 공감하는 반응이 일부 있다. |
| 5–6 | 문제는 있으나 막연하거나 한 사람의 사례에 그친다. |
| 3–4 | 불평 수준이다. 해결하려는 의지나 대상이 불명확하거나, AI와 관련이 약하다. |
| 0–2 | 문제가 아니다(잡담·밈·홍보), 또는 AI와 무관하다. |

## 판단 요령
- **추천 수·댓글 수는 합의의 근거가 아니다.** 댓글 내용에 같은 경험이 실제로 적혀 있는지로 판단한다.
- 누가(직군·상황), 무엇을(작업), 왜 불편한지(시간·비용·품질)를 이유에 한 문장으로 적는다.
- 이미 좋은 해결책이 널리 쓰이는데 모르는 사람의 질문이면 5점 이하로 둔다.
- 글쓴이·댓글 작성자의 개인정보(실명, 회사 내부 정보)는 요약에 옮기지 않는다.
- 요약은 한국어 한 문장, 태그는 구체적인 주제 3~5개(예: `meeting-notes`, `invoice-processing`, `code-review`).
