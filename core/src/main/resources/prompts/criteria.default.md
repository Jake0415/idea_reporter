# 내 기준

- **개발 범위:** 혼자서 3개월(약 12주) 안에 첫 버전(MVP)을 만들 수 있는 것. 큰 팀이 필요한 일은 제외.
- **대상 고객:** 제한 없음 — 개인 개발자·프리랜서, 소규모 팀(2~50인), 비개발 일반 사용자, 중견 이상 기업(B2B) 모두 가능. 기업 고객이면 1인이 감당할 영업·보안 부담도 실현성 판단에 반영한다.
- **관심 분야:** 업무 자동화, 개발 도구, 개인 생산성(우선 검토).
- **제외 분야:** 모델 직접 학습·GPU 인프라가 필요한 것, 전용 하드웨어가 필요한 것.
- **수익화:** 월 구독(SaaS), 일회성 판매(설치형·템플릿·확장), 오픈소스 + 유료 팀판, 광고·제휴 모두 가능. 아이디어에 가장 맞는 방식을 제안한다.
- **선호:** 이미 있는 도구의 빈틈(가격·설치형·특정 언어·특정 대상)을 파고드는 아이디어.
