# 내 기준

- **개발 범위:** 혼자서 2~4주 안에 첫 버전을 만들 수 있는 것. 대규모 모델 학습, 전용 하드웨어, 큰 팀이 필요한 일은 제외.
- **대상 고객:** 개발자, 소규모 사업자(1~20명).
- **관심 분야:** 업무 자동화, 개발 도구, 개인 생산성.
- **제외 분야:** 하드웨어, 의료 진단·법률 판단처럼 책임이 큰 영역, 성인·도박, 개인정보를 대량으로 모으는 서비스.
- **수익화:** 월 구독(소액) 우선, 1회 구매도 가능.
- **선호:** 이미 있는 도구의 빈틈(가격·설치형·특정 언어·특정 대상)을 파고드는 아이디어.
